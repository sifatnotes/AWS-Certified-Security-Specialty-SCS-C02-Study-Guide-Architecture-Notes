## Exam Overview

The **AWS Certified Security – Specialty (SCS-C02)** validates expert-level technical expertise in securing and hardening AWS workloads across identity, infrastructure, data protection, and incident response.

| Parameter | Details |
| :--- | :--- |
| **Vendor** | Amazon Web Services (AWS) |
| **Exam Code** | SCS-C02 |
| **Delivery Provider** | [Pearson VUE](https://home.pearsonvue.com/aws) |
| **Passing Score** | 750 / 1000 (Scaled Score) |
| **Format** | 65 Questions (Multiple Choice, Multiple Response, Ordering, and Matching) |
| **Duration** | 170 Minutes |
| **Validity** | 3 Years |

## Target Audience

- **Cloud Security Engineers** implementing automated perimeter defenses, IAM boundary controls, and KMS key topologies.
- **DevSecOps Engineers** building CI/CD pipeline security gates, AWS Config auto-remediations, and vulnerability scanning workflows.
- **Security Architects** designing multi-account governance using AWS Organizations, Control Tower, and Security Hub.
